# Novel Chat Importer

这是一个 **SillyTavern 前端扩展**，用于把本地 TXT 小说导入当前聊天记录。

它主要用于：

- 导入长篇小说文本到 SillyTavern
- 按章节或字数切分楼层
- 搜索关键词在章节和楼层中的命中位置
- 替换、批量替换小说文本
- 在导入前预览章节和楼层内容

---

## 功能概览

### 核心功能

- 读取本地 `TXT` 文件
- 支持 `UTF-8` 和 `GBK / GB18030` 编码
- 自动识别章节标题
- 支持按字数切分楼层
- 支持“一章一楼”模式
- 支持“章节过长时继续按字数切分”
- 导入到当前聊天

### 预览功能

- 章节式原文预览
- 楼层预览
- 搜索关键词命中数量显示
- 章节/楼层默认摘要显示，可点击展开全文
- 分批加载，避免一次性渲染过多内容

### 搜索功能

- 关键词搜索
- 可区分大小写
- 显示命中章节
- 显示命中楼层
- 支持“只显示命中章节/楼层”
- 搜索结果可跳转楼层预览

### 替换功能

- 单个关键词替换
- 批量规则替换
- 替换前统计命中数量
- 替换后自动刷新预览和搜索结果

### 导入模式

- AI消息
- 用户消息
- AI / 用户轮流，AI先发
- AI / 用户轮流，用户先发

### 导入范围

- 全部内容
- 按章节范围导入
- 按楼层范围导入
