# Novel Chat Importer

把本地 TXT 小说导入 SillyTavern 的扩展，同时提供聊天文末的剧情控制栏、固定章节常驻注入，以及原文 / 固定章节 / 对照生成阅读器。

当前版本：**3.0.0**

---

## 功能

### 小说导入

- 读取本地 `TXT`，支持 `UTF-8` 与 `GBK / GB18030` 编码
- 自动识别章节标题，支持按章节或按字数切分楼层
- 支持「一章一楼」和「章节过长时继续按字数切分」
- 导入范围：全部内容 / 章节范围 / 楼层范围
- 导入模式：AI 消息 / 用户消息 / AI 与用户轮流

### 预览、搜索与替换

- 章节原文预览、楼层预览，默认 800 字摘要，可展开全文
- 关键词搜索，区分大小写，显示命中章节和楼层
- 单个关键词替换、批量规则替换，替换前统计命中数量

### 剧情控制栏

- 挂在聊天最后一条 AI 消息下方，可收起 / 展开
- 跟随范围：起止章节、步数、进度条、上一批 / 下一批
- 一键查看当前批次原文，或对照生成内容与原文的重合度
- 从角色绑定的世界书自动恢复章节范围

### 固定章节

- 钉住的章节常驻注入，不随跟随范围滚动
- 支持连续范围或单章列表
- 「已钉章节 → 原文」打开固定章节阅读器
- 可配置注入位置、顺序和深度

### 移动端

- 控制栏收起 / 展开、字段换行、阅读器标签页和底部按钮均按窄屏适配
- 320px 宽度起可用，无横向溢出

## 安装

### 方式一：SillyTavern 扩展

把整个目录放到：

```txt
SillyTavern/
└─ public/
   └─ scripts/
      └─ extensions/
         └─ third-party/
            └─ novel-chat-importer/
               ├─ manifest.json
               ├─ index.js
               └─ style.css
```

然后在 SillyTavern 的「扩展」里启用 **Novel Chat Importer**。样式由 `index.js` 运行时注入，`style.css` 只用于满足 manifest 引用。

### 方式二：酒馆助手脚本

直接导入：

```txt
dist/novel-chat-importer.tavernhelper.json
```

适合已经在用酒馆助手（TavernHelper）的环境，不需要再装扩展。

## 说明

- 剧情控制栏默认关闭，需要在扩展设置里开启「显示聊天页剧情控制栏」。
- 固定章节会写入当前角色绑定的世界书；换角色或换聊天后，会尝试从世界书恢复范围和钉住状态。
- 导入前建议先备份当前聊天，尤其是长篇小说的批量导入。
